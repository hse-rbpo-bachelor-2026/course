# Разработка безопасного программного обеспечения

Публичный репозиторий дисциплины для студентов бакалавриата образовательной программы 09.03.04 «Программная инженерия» НИУ ВШЭ.

- **Учебный год:** 2026/2027  
- **Объём:** 5 зачётных единиц, 190 часов  
- **Формат:** 14 лекций, 14 семинаров, командный проект и четыре элемента контроля  
- **Репозиторий:** `hse-rbpo-bachelor-2026/course`

## С чего начать

**Первый семинар → [S01. Выбор и описание командного проекта](seminars/S01/README.md).** Читать весь репозиторий заранее не требуется.

Далее открывайте README [текущего семинара](seminars/README.md): в нём указаны подготовка, задания, результат и действия после занятия.

По организационным вопросам обращайтесь к [руководству студента](student-guide.md), включая раздел о GitHub, LMS и Telegram.

## О курсе

Команда из трёх студентов (из двух — по согласованию) развивает один небольшой продукт:

> **контекст → требования и угрозы → проектные решения → реализация → проверка → исправление → повторная проверка → решение о выпуске**

Основной поддерживаемый стек — **C#/.NET**. Другой стек допустим, если позволяет выполнить требования курса; выбор проверяется при ранней калибровке проекта.

## Публикация материалов

Лекции и задания семинаров публикуются перед соответствующими занятиями, шаблоны — к первому обязательному использованию, регламенты контроля — заранее. Будущие артефакты до введения задания создавать не требуется.

Ключевые материалы репозитория также дублируются в SmartLMS. Назначение площадок и порядок действий при расхождении копий описаны в руководстве студента.

Закрытые решения контроля, ключи и преподавательские материалы здесь не размещаются. Учебные разборы и эталоны самопроверки открываются в объявленный момент, без преждевременного раскрытия следующих заданий.
