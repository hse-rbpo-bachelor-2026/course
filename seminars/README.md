# Семинары

В этом разделе последовательно публикуются задания S01–S14. Основная точка входа каждого опубликованного семинара:

```text
seminars/SNN/README.md
```

В каталоге семинара могут дополнительно находиться публичный кейс, исходные данные или другой входной материал. Исходный код практических объектов S06–S12 размещается в отдельных репозиториях.

Каждый семинар длится **80 минут**. Результат занятия и самостоятельная доработка разделены в его README.
