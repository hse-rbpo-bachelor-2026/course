# Шаблоны

Шаблон публикуется к первому обязательному использованию. Будущие артефакты заранее создавать не требуется.

## Как использовать

1. Откройте шаблон по ссылке из текущего задания.
2. Скопируйте только содержимое блока «Форма для копирования».
3. Замените подсказки результатами своего проекта и удалите незаполненные примеры.

Пояснения и учебные ссылки за пределами блока переносить не нужно. Для отдельного документа, который появится позднее, добавьте ссылку из существующего `PROJECT.md` или README проекта. Кратких записей достаточно, если обязательные сведения понятны и проверяемы.

Шаблоны задают **обязательное содержание и рекомендуемую форму**. Таблицы можно заменить блоками или другим понятным представлением. При изменении формы команда отвечает за полноту и удобство проверки результата.

## Имена файлов

- `PROJECT.md` и `AI_USAGE.md` создаются после S01 в корне репозитория.

У `PROJECT.md` до завершения ранней калибровки обязательна базовая структура. После неё оформление можно адаптировать с сохранением сведений и ссылок; имя файла сохраняется весь курс.

## Доступно сейчас

[Паспорт проекта](project-passport.md) — первая форма для выбора и ограничения продукта.

Обязательный `AI_USAGE.md` создаётся независимо от существенного использования ИИ. Декларация и форма записи находятся в [политике ИИ](../ai-usage.md); отдельный шаблон не нужен.

Следующие шаблоны будут появляться здесь вместе с заданиями, в которых они впервые используются. Будущие формы заранее создавать не требуется.

Готовый шаблон репозитория команды не предоставляется: организуйте его по [требованиям к проекту](../project.md).
